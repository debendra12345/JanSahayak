## 🎯 DEMO FLOW

### PART 1: Guided Application with Screen-Sharing (2 mins)

#### Step 1: Navigate to Guided Application
```
1. Go to Dashboard
2. Click any "Recommended Scheme" → "Start Guided Application"
   OR directly visit: /guided-apply/scheme_123

```

#### Step 2: Show Step Navigation
```
1. Point to "Step Indicator" at top
2. Click through steps 1-3 to show navigation
3. Show "Current Step" card on left
4. Explain what each step accomplishes
```

#### Step 3: Demo Screen-Sharing Feature
```
1. Click "Quick Actions" → "Share Screen for Help"
2. Show permission popup: "This site wants to capture your screen"
3. Click "Share" (or "Allow")
4. Point to video preview showing your desktop
5. Click "Analyze Current Screen" button
6. Show guidance panel appearing with:
   - "What I See": Page title
   - "Detected Elements": Fields/buttons
   - "What You Should Do": Step-by-step instruction
   - "Next Step": What to do next
7. Click "Stop Sharing" - clean exit
```

#### Step 4: Show Camera Fallback
```
1. Scroll down or click "Use Camera Mode"
2. Click "Start Camera"
3. Grant camera permission
4. Show live camera feed
5. Click "Capture & Analyze"
6. Show same guidance format
7. Click "Stop Camera"
```

### PART 2: Reminder Management (1-2 mins)

#### Step 1: View Reminders Dashboard
```
1. Go to Reminders page (/reminders)
2. Show dashboard:
   - Upcoming count
   - Completed count
   - Total count
3. Show reminder list with:
   - Status icon (clock, checkmark, alert)
   - Title and description
   - Days until reminder
   - Urgency badge (red for 3-day warning)
```

#### Step 2: Create New Reminder
```
1. Click "Add Reminder" button
2. Fill form:
   - Title: "Check Application Status"
   - Description: "Review if there are any updates"
   - Date: Select 1 week from now
   - Application: Select from dropdown (optional)
3. Click "Create Reminder"
4. Show new reminder appears at top of list
5. Explain form validation (required fields, future dates)
```

#### Step 3: Edit Reminder
```
1. Find a reminder
2. Click "Edit" (pencil icon)
3. Change date to different value
4. Change title slightly
5. Click "Update Reminder"
6. Show reminder updates in list
```

#### Step 4: Filter Reminders
```
1. Show "Filter" tabs: All, UPCOMING, COMPLETED, DISMISSED
2. Click "UPCOMING" - filters to show only upcoming
3. Click "COMPLETED" - shows completed reminders
4. Click "All" - back to full list
```

#### Step 5: Mark Complete & Delete
```
1. Find "upcoming" reminder
2. Click ✓ (checkmark) - marks as completed
3. Show it moves to completed category (green)
4. Click 🗑️ (trash) on a reminder
5. Show it disappears from list
```

## ❓ COMMON QUESTIONS & ANSWERS

**Q: Is JanSahayak reading my screen?**  
A: No. The browser captures one frame only when YOU click "Analyze." We show detected elements and guidance - never personal data.

**Q: What about sensitive information like passwords?**  
A: We detect sensitive fields and warn the user. Passwords are never captured or shown.

**Q: Can you record my screen?**  
A: No. JanSahayak never records anything. You control what's shared via browser permissions.

**Q: Why screen-sharing instead of walking through their website?**  
A: Because every government portal is different. By seeing what they see, we provide specific step-by-step guidance that works for their actual portal.

**Q: How are reminders stored?**  
A: Locally on their device for now. In production, they'll sync to their account and send notifications.

**Q: Can I link reminders to applications?**  
A: Yes! Optional feature. Helps organize reminders by scheme.
